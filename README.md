# Push-Up Counter — first native Android milestone

This is a native Kotlin Android prototype that counts push-ups using on-device Google ML Kit pose detection. It is intentionally small so each part can be tested independently.

## Current milestone

- CameraX live preview.
- ML Kit fast `pose-detection` model in `STREAM_MODE`.
- 480x360 analysis resolution and `STRATEGY_KEEP_ONLY_LATEST` to prioritize low latency.
- Skeleton overlay for shoulders, elbows, wrists, hips, knees and ankles.
- Push-up state machine: extended arms → elbows bent → extended arms.
- Reset button and basic feedback.
- No backend, login, video recording, or cloud upload.

## Build from GitHub Actions

Push this folder to a GitHub repository. The workflow at `.github/workflows/build-apk.yml` builds a debug APK and uploads it as an artifact. Download it from the workflow run on your phone.

The included `gradlew` is a minimal fallback for environments that already have Gradle. GitHub-hosted runners normally have Gradle available. If the runner does not, replace it with the standard Gradle Wrapper generated by `gradle wrapper` or Android Studio.

## Test checkpoints

1. Install the APK and grant camera permission.
2. Confirm the preview opens and the skeleton follows your body.
3. Confirm the status text changes when both arms are visible.
4. From a side view, bend elbows below roughly 105 degrees: the state should show `DOWN`.
5. Extend arms above roughly 155 degrees: the count should increase once.
6. Press `RESET` and verify the count returns to zero.

Thresholds are starting values, not a claim of perfect form detection. Test on the target phone and adjust `PushUpDetector` after the camera pipeline is confirmed.

## Important implementation notes

- `ImageProxy` is closed in `addOnCompleteListener`, including failed inference.
- Only the latest camera frame is kept when inference is busy.
- The detector runs on a background executor; UI updates run on the main thread.
- Processing is on-device. Camera frames are not uploaded or saved.
